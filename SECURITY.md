# Security Policy

This project is a local hackathon prototype. Do not enter real customer, payment, or confidential data.

Report security issues privately to the repository owner. Do not include credentials or personal data in public issue reports. Rotate any credential that may have been exposed.

PayPal integration is Sandbox-only. AI requests send user-entered evidence to the configured provider; configure a provider only if you are permitted to share that data. Keep API keys in `.env`, which is ignored by Git.
